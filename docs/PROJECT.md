# One Global Defence Ecosystem — product identity

**Official name:** One Global Defence Ecosystem

**Short name:** OGDE (official brand; acronym letters are a deliberate brand choice)

**GitHub organisation/account:** `ymmiah`

**GitHub repository:** [ymmiah/OGDE](https://github.com/ymmiah/OGDE)

**Tagline:** Defend locally. Verify globally. Recover together.

**Mission:** Make verifiable security intelligence available to every organisation without requiring central control of its infrastructure.

**Initial product:** Offline verified advisory matching, opt-in live OSV vulnerability lookup, local audit evidence.

**Audience:** Small security teams, open-source maintainers, schools, charities, WordPress agencies, infrastructure administrators and security researchers.

**Non-goals for version 0.1:** global surveillance, unauthorised network scanning, remote code execution, autonomous remediation, universal vulnerability coverage, and unverifiable claims of AI-powered immunity.
