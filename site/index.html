Cyber defence intelligence

Verified intelligence in. A finding you can trust out.

An open, neutral platform for sharing verifiable threat intelligence across organisations, especially those running critical infrastructure.

The loop

OGDE publishes signed evidence. Each organisation verifies it, matches it against assets it already owns, and decides what to do. Inventories and decisions stay on that organisation’s own infrastructure.

  1. 01 — In A signed feed of advisories. A signature shows who published the record. It does not, by itself, make the claim true.
  2. 02 — Match Compare that evidence with a local inventory: WordPress core, plugins and themes, plus Composer and npm lockfiles. Nothing is uploaded.
  3. 03 — Out A finding with a confidence level, the evidence it came from, and a priority a person can challenge. OGDE does not change the system.

Current status

Published
v0.2.2 command-line preview in the ymmiah/OGDE repository. Signed advisory feeds, local matching, explainable human review.
In progress
v0.3, the verified loop: WordPress sites and CI/CD pipelines first. Specifications are in the repository. A local inventory command and a finding report are the first slice. TUF and Sigstore are specified and not yet implemented.
Not yet
A public feed, accounts, a dashboard, or any remote action on a customer system. The v0.3 pilot gate — five sites for four weeks, with a published false-positive rate — has not been met.

Try the preview

Install from a clone of the repository. The commands below stay on your machine. They do not send an inventory anywhere.

python -m pip install -e .
ogde inventory \
  --wordpress examples/demo-site/wordpress \
  --composer-lock examples/demo-site/composer.lock \
  --package-lock examples/demo-site/package-lock.json \
  --out .ogde-local/inventory.cdx.json

ogde report \
  --findings examples/findings.example.json \
  --vex examples/vex.example.json \
  --out .ogde-local/findings.json \
  --markdown .ogde-local/findings.md

Exit code 2 means a visible finding. That is expected for the synthetic example. Exit code 0 means none. Exit code 1 means the input was rejected. The older assess command is described in the v0.2.2 walkthrough.

What this site does not do

  • No sign-in, no accounts and no cookies.
  • No analytics, no forms and no scripts.
  • No upload of inventories, findings or visitor data.
  • No claim that a signed feed, or this page, is proof of an attack.

Software in the repository is released under the MIT licence. Data-source terms, when a feed is published, are separate and are recorded in the repository.
